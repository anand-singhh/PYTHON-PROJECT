# Multiple Time Zone Clock (Python Tkinter)

A full-screen digital world clock application built using **Python Tkinter** that displays real-time clocks for multiple countries.

---

# Features
- Live time updates (every second)
- Multiple international time zones
- Full-screen display
- Clean digital-style UI
- Exit using ESC key

#Technologies Used
- Python
- Tkinter
- datetime
- pytz

# Supported Time Zones
- India 🇮🇳 (Asia/Kolkata)
- USA 🇺🇸 (US/Eastern)
- UK 🇬🇧 (Europe/London)
- Dubai 🇦🇪 (Asia/Dubai)
- Japan 🇯🇵 (Asia/Tokyo)
- Australia 🇦🇺 (Australia/Sydney)
